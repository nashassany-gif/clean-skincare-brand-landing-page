Demo disclosures & policy readiness

This is a concept storefront, not an approved live shop. Products, pricing, formulas, reviews and delivery rates are examples. This page describes the demo and outstanding decisions; it is not a final sales contract or a substitute for legal review.

Data in this demo

Test orders store contact and delivery details in the site's server database. Administrators with access can read them. Use fictional data only. The browser stores only the latest order number, private access token and save time in local storage, not a saved copy of contact details. It retrieves order details from the server after refresh. Saved access is discarded when the page next opens after seven days. On a shared device, remove it using “Forget this order on this device” on the order page. This clears access on that device; it does not delete the server record.

Newsletter collection is disabled by default; no marketing email is sent. No analytics or third-party advertising cookies are intentionally added by this demo. Payment-provider credentials and administrator credentials are never stored in the browser by the application.

Before accepting real customer data, the operator must publish its identity and contact channel, retention schedule, deletion/request procedure and any cross-border processing disclosures. These details are not yet confirmed.

Shipping

No real fulfilment service is available. Any displayed rate, destination or delivery estimate is illustrative. The operator must confirm shipping regions, carriers, cut-off times, delivery windows and tax treatment before live orders.

Returns & refunds

No live return policy is approved. Before trading, the operator must confirm the return window, product eligibility, return-shipping responsibility, contact procedure and refund times. The presence of an administrator refund tool is not a promise of any particular commercial return policy.

Terms readiness

Real checkout must remain disabled until product/currency eligibility, tax obligations, policies and payment-provider acceptance have been reviewed. Demo order records are not a promise to ship the fictional products.

Contact

A customer-support email and legal business identity have not been supplied. No working support channel is advertised. For now, contact the person who supplied this demo. This is a release blocker for live commerce.
